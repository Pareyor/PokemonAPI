# ⚡ PokéPulse TCG

📘 **La documentación completa está en el [README principal](../../README.md)**: cómo se juega, sobres, arena, arquitectura, API y solución de problemas.

## Arranque rápido

```bash
./start.sh   # PostgreSQL (Docker) + backend + frontend
./stop.sh    # parar todo
```

Abre **http://localhost:3001** e inicia sesión con `entrenador` / `pokemon123`.

> Necesitas **Docker Desktop** abierto, **Java 21**, **Maven** y **Node.js 18+**.
